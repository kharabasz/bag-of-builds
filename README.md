# Bag of Builds

A backup of the build orders shared on the Bag of Builds Discord for StarCraft: Brood War (and Remastered).

Each build has its own folder with a `README.md` holding the build order, timings and notes. Most also include example replays (`.rep`). Folders are grouped by race and matchup: `pvt` is Protoss vs Terran, `zvp` is Zerg vs Protoss, and so on.

## Watching the replays

Copy a `.rep` file into your StarCraft replay folder, usually `Documents\StarCraft\Maps\Replays`, then open it from **Replays** in the game.

## Adding a build

Create a folder under `<race>/<matchup>/` with a short snake_case name. Add a `README.md` that starts with a `# Title`, followed by the build order in a code block and any notes, plus replays if you have them. Then add a row to the table above.
